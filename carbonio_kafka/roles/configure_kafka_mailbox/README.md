# Configure Kafka Mailbox

This role configures Carbonio Application Servers to use the Kafka brokers defined in the inventory.

## Responsibilities

The role:

- configures the global Kafka broker list;
- applies the configuration on Application Servers;
- verifies and displays the configured broker list.
