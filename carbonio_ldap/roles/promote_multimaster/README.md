# Promote Multi-Master LDAP

This role promotes an existing Carbonio LDAP replica to a Multi-Master Replication node.

## Responsibilities

The role:

- enables Multi-Master Replication on the existing master;
- promotes the LDAP replica;
- updates LDAP master URLs;
- restarts Carbonio services on both LDAP nodes.
